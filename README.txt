POUNDGEM INVOICE GENERATOR - iPhone PWA

1. Create a free account with a static HTTPS host such as Cloudflare Pages or GitHub Pages.
2. Upload the contents of this folder (index.html, sw.js, manifest.webmanifest, icon.png) to the site root.
3. Open the resulting HTTPS URL in Safari on your iPhone.
4. Tap Share > Add to Home Screen > Open as Web App > Add.
5. Open the new Home Screen icon. Complete business settings first.
6. Export backups frequently to Files / iCloud Drive. Storage is local to the app and can be lost.

The hosted website code is public; invoice data is NOT uploaded by this application. Avoid adding personal invoice data to hosted files.

The app does not automatically sync orders or emails, and the print/PDF feature uses iPhone's print/share interface. This is an initial version, not accounting or tax advice.
